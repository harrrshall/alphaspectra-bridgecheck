Install, generate a reference bundle, audit.

python -m pip install \
  https://harrrshall.github.io/alphaspectra-bridgecheck/downloads/bandtrace/alphaspectra_bandtrace-0.1.0-py3-none-any.whl

bandtrace make-reference-bundle /tmp/bandtrace-reference
bandtrace audit /tmp/bandtrace-reference \
  --output-dir /tmp/bandtrace-report

Python 3.10+ on Linux. The completed-audit path requires renameat2(RENAME_NOREPLACE).
