# Examples

`vnir_example.csv` and `predict_request.json` contain the same anonymized CABO training
biological-group median in absolute decimal reflectance. They are provided solely to exercise the
interfaces; they are not an independent validation case. CABO attribution and source terms are in
[`../DATA_ATTRIBUTION.md`](../DATA_ATTRIBUTION.md).

The browser's built-in “Load model demo” is different: it uses a generated state from the frozen
candidate bank and explicitly labels that input as model-derived rather than measured.
